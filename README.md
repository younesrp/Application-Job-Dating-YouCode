# 🚀 Plateforme Job Dating - YouCode

Une application web complète pour gérer le processus de recrutement (Job Dating) entre les étudiants de YouCode et les entreprises partenaires.

## 🌟 Fonctionnalités

### 👨‍💼 Administrateur (Admin)
- **Tableau de bord (Dashboard)** : Statistiques globales (Offres, Candidatures, Utilisateurs).
- **Gestion des utilisateurs** : Ajouter/Modifier/Supprimer des étudiants et des entreprises.
- **Validation des offres** : Approuver ou rejeter les annonces publiées.
- **Suivi des candidatures** : Voir l'état de chaque postulation.

### 🏢 Entreprise
- **Gestion des offres** : Créer, modifier et supprimer des offres d'emploi/stage.
- **Gestion des candidats** : Voir les profils des étudiants qui ont postulé.
- **Statut** : Accepter ou refuser une candidature.

### 👨‍🎓 Apprenant (Étudiant)
- **Consultation** : Parcourir les offres disponibles.
- **Postulation** : Postuler aux offres avec un message personnalisé.
- **Suivi** : Voir l'état de ses candidatures (En attente, Validée, Refusée).

---

## 🛠️ Technologies Utilisées

- **Langage** : PHP 8 (Architecture MVC).
- **Base de données** : MySQL.
- **Frontend** : Twig (Moteur de template), TailwindCSS.
- **Outils** : Composer, Git.
- **Serveur** : Apache (XAMPP/MAMP).
